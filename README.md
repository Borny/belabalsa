## About

This is a professional website about Bela Balsa.
Bela is a professional dancer, singer and actress.
This website will showcase photos, videos, YouTube links, songs and more about her work.

Tabs:

- Main: Choreography/movement director => videos of Bela and projects she worked on: studio, show, street... check: https://www.joranerest.com/personal-work
- Singing: albums, songs, short clip 3s like Spotify
- Cabaret: photos, videos from LoliStar, BleuBlancCiel
- About: short bio

Keywords: movement director, chanteuse, danseuce, chorégraphe, comédienne, cabaret, Bordeaux, française, portugaise, directrice artistique, danse contemporaire, forro, brésil, Compagnie Bela et Come, Show années 80/90, revues, spectacle vivant, événementiel, professeure de danse, cours, stage, festival, samba de gafieira, ...

The default language is french but the website will be translated in english and portuguese.
